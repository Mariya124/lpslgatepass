# Inventory Gate Pass Manager

Open `index.html` in a modern browser.

Features:
- Dashboard
- Gate Pass creation/edit/delete/search
- Unlimited item rows
- Inventory database
- LocalStorage persistence
- HTML/CSS template manager
- Import/export templates
- Live template preview
- Print
- JSON backup/restore
- CSV inventory export
- Company settings
- Dark mode

To add a Gate Pass format, open Templates and import/edit an HTML file using placeholders such as:
`{{gate_pass_no}}`, `{{employee_name}}`, `{{items}}`, `{{total_quantity}}`.
